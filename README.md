# Наша історія для Насті ❤️ — GitHub Pages

Цей архів спеціально адаптовано для **GitHub Pages**, без збірки або GitLab CI.

## Як запублікувати без термінала

1. Створи **Public** репозиторій на https://github.com/new, наприклад `nasha-istoriya`. (На GitHub Free GitHub Pages потребує публічного репозиторію.)
2. На сторінці репозиторію натисни **Add file → Upload files**.
3. **Розпакуй цей ZIP** і перетягни **весь вміст розпакованої папки** (не ZIP) на сторінку завантаження. Файли `index.html`, `styles.css`, `app.js`, `content.js` мають опинитися **у корені репозиторію**, а `assets/` та `photos/` — бути папками в корені.
4. Натисни **Commit changes** (або кнопку для збереження файлів із аналогічною назвою).
5. Зайди у **Settings → Pages**. У розділі **Build and deployment** вибери **Deploy from a branch**, гілку `main`, папку `/(root)` і натисни **Save**.
6. Коли опублікується, у **Settings → Pages** натисни **Visit site**. Типова адреса: `https://<username>.github.io/nasha-istoriya/` (залежить від назв акаунта й репозиторію).

## Вміст

- `index.html` — головна сторінка
- `styles.css`, `app.js` — оформлення й інтерактиви
- `content.js` — лист, підписи, усі тексти
- `photos/` — 10 справжніх фото (`01.webp`...`10.webp`)
- `assets/` — фони, SVG і мелодія `ambient.mp3`
- `.nojekyll` — GitHub Pages не має обробляти сайт через Jekyll

## На що звернути увагу

- **Не завантажуй ZIP як один файл**: GitHub Pages не розпаковує його в сайт. Потрібні окремі файли й папки.
- Публічний сайт і публічний репозиторій означають, що фотографії та лист можна переглянути будь-кому в інтернеті, хто знайде посилання чи репозиторій. Не викладай, якщо це для вас не ок.
- На iPhone музика починає звучати лише після першого натискання на сайті — це нормальне обмеження Safari.
- Після завантаження перевір сайт на телефоні, особливо розділ із загадкою, галерею і музичну кнопку.
- Змінювати тексти можна в `content.js`, а фото — замінюючи файли з тими самими назвами у `photos/`.
